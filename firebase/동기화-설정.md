# 강사 화면 자동 따라가기 설정

## 접속 주소

- 강사: `slides.html?admin` → 로그인과 진행 제어
- 청중: `slides.html` → 잠금 ON일 때 강사 장 따라가기, 잠금 OFF일 때 자유 이동
- 프로젝터: `slides.html?screen` → 강사 장 표시
- Firebase 설정 전: 모든 슬라이드 자유 열람. 동기화·관리자 로그인은 아직 작동하지 않음

## Firebase 콘솔 체크리스트

- [ ] **프로젝트와 웹 앱**: Firebase 콘솔에서 프로젝트 생성 → 프로젝트 설정 → 내 앱 → 웹 앱 등록. 제공된 `firebaseConfig`의 `apiKey`, `authDomain`, `projectId`, `appId`를 `firebase/firebase-config.js`에 입력. 비밀번호를 이 파일에 넣지 않기.
- [ ] **Realtime Database**: 빌드 → Realtime Database → 데이터베이스 만들기. 생성 후 보이는 데이터베이스 URL을 같은 설정 파일의 `databaseURL`에 입력. `DECK_ID`는 이 강의만의 영문·숫자·하이픈 식별자로 지정.
- [ ] **Authentication**: 빌드 → Authentication → 시작하기 → 로그인 방법 → 이메일/비밀번호 사용. 사용자 탭에서 강사 계정 추가. 설정의 승인된 도메인에 공개 Vercel 도메인 `webslide-81-lecture-20261001.vercel.app`을 등록.
- [ ] **규칙**: Realtime Database → 규칙에 `firebase/database.rules.json`의 내용을 그대로 붙여넣고 게시. 규칙은 상태 읽기를 공개하고 상태 쓰기는 `admins/{UID} = true`인 인증 계정으로 제한.
- [ ] **admins**: Authentication → 사용자에서 강사 UID를 복사. Realtime Database → 데이터에서 `admins/{강사 UID}` 경로의 값을 Boolean `true`로 추가. 문자열 `"true"`가 아님.
- [ ] **설정 배포**: `firebase/firebase-config.js` 변경을 GitHub에 반영하고 Vercel Production 배포 상태가 Ready인지 확인.
- [ ] **두 기기 확인**: 강사 주소에서 로그인 → 청중 주소를 다른 기기나 시크릿 창에서 열기 → 강사가 다음 장으로 이동. 잠금 ON이면 청중도 같은 장으로 이동. 잠금 OFF이면 청중 직접 이동 가능. PDF OFF이면 사이트의 PDF 버튼·P 단축키가 꺼지고 인쇄 화면에 슬라이드가 표시되지 않음.

강사 화면 자동 따라가기는 Realtime Database 연결과 관리자 UID 등록까지 마친 뒤 사용 가능. 현재 `firebase-config.js`는 자리표시자이므로 실시간 동작은 확인되지 않음. PDF 스위치는 웹페이지의 인쇄·저장 화면을 제어하는 운영 기능이며, 브라우저 화면 촬영까지 막는 보안 기능은 아님.
