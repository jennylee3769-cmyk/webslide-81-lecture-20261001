# 강사 화면 자동 따라가기 설정

`slides.html`의 일반 주소는 수강생 화면, `slides.html?admin`은 강사 화면, `slides.html?screen`은 프로젝터 화면입니다.

1. Firebase 프로젝트에 웹 앱과 Realtime Database를 만듭니다.
2. `firebase/firebase-config.js`에 웹 앱 설정값과 데이터베이스 URL을 입력하고, `DECK_ID`를 이 강의만의 영문·숫자·하이픈 이름으로 정합니다.
3. Firebase Authentication에서 이메일/비밀번호 로그인을 켜고 강사 계정을 추가합니다.
4. `firebase/database.rules.json` 규칙을 Realtime Database 규칙에 게시합니다.
5. 강사 계정으로 한 번 로그인해 UID를 확인하고 데이터의 `admins/{UID}` 값을 Boolean `true`로 등록합니다.
6. Firebase 동기화는 HTTPS 또는 localhost에서 확인합니다. Firebase 설정 전에도 슬라이드 이동·전체보기·프롬프트 복사는 파일 직접 열기(file://)에서 사용 가능하며, 실시간 동기화에는 웹 서버와 Firebase 설정이 필요합니다.
7. 강사 화면에서 로그인 후 장을 넘기면 동기화됩니다. 수강생은 기본적으로 강사 위치를 따라가며, 잠금을 풀면 직접 이동할 수 있습니다.

Firebase 설정 전에는 자동 동기화가 연결되지 않습니다. 설정 오류나 연결 끊김이 있으면 화면의 연결 상태를 확인하세요. `admin.html`의 localStorage 목업은 이 동기화에 연결되지 않습니다.
