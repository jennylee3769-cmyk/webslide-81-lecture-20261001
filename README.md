# 강의 사이트 제작 노하우

AI 리터러시 클래스 이정임 강사의 2026년 10월 1일 수업 사이트.

- `index.html`: 강의 안내와 강사 소개
- `slides.html`: 1~5교시, 81장 웹슬라이드와 실습 프롬프트
- `admin.html`: 서버 없이 이 브라우저에 저장하는 관리자 화면 시제품
- `slides.html?admin`: Firebase 연결 뒤 강사가 로그인하는 실시간 진행 화면
- `firebase/동기화-설정.md`: 동기화 설정 절차

Firebase 설정값은 아직 비어 있습니다. 설정 전에는 청중이 슬라이드를 자유롭게 볼 수 있고, 강사 화면 자동 따라가기는 작동하지 않습니다.
